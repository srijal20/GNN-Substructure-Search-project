1. Title of the Project

GNN Molecular Substructure Search: Accuracy vs. Speed Trade-offs Against Classical Fingerprint Screening

2. Problem Statement

Exact molecular substructure search using combinatorial graph matching (RDKit’s Ullmann/VF2-based HasSubstructMatch) provides reliable ground truth but scales poorly across large chemical libraries. We train Graph Neural Networks (GNNs) to act as an ultrafast approximate filter predicting whether a chemical query fragment Q occurs inside target molecule T. Our goal is to explore the speed-accuracy Pareto frontier when combining a learned GNN candidate shortlist with exact verification, benchmarked directly against industrial cheminformatics standards (Chem.PatternFingerprint).

3. Extensions to Prior Work  In-Progress
  • NeuroMatch-Style Order Embeddings: Formulated substructure containment as a partial order in a learned non-negative embedding space (zQ ≤ zT element-wise) optimized via max-margin violation loss (E(Q, T) = ||max(0, zQ − zT)||2). This enables precomputing database embeddings once for instant matrix screening.
  • Bond-Aware Molecular Graph Encoding: Replaced generic graphs with chemistry-aware GINEConv layers featuring 10-dimensional one-hot atom vectors and 4-dimensional bond type vectors matching query SMARTS semantics.
  • Two-Stage Cascaded Screening: Implemented a cascade where the GNN shortlists candidates at a calibrated 98% recall threshold, followed by RDKit exact verification on only the shortlist.
4. How Do We Feel?  In-the-zone
